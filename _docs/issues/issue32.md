# Issue 32: Describe the problem, features and expected behaviour in the README

Status: open (not yet groomed)

## Goal

A reader of the README understands what problem the application solves, what
it does, and how it is expected to behave before reading any operational
detail.

## Acceptance criteria

- [ ] The README states the problem the application solves and who it is for.
- [ ] The README lists the main features: ingredient management, recipe
      management, and the recipe cost calculator.
- [ ] The README describes the expected behaviour of a calculation, with a
      worked example.
- [ ] The README states what is out of scope, consistent with
      `_docs/architecture.md`.

## Out of scope

- Operational and deployment documentation, which stays in its current
  sections and in `docs/operator-guide.md`.

## Constraints

- Change only `README.md`.
